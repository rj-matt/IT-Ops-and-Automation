# Software watchlist for Get-InstalledSoftwareReport.ps1 and get-installed-software-report.sh (E2).
# Keep this file next to those scripts. Edit it for the MSP's own needs; one entry per line:
#
#   Type|Platform|Name pattern|Version pattern|Date|Reason|Source|Checked
#
#   Type      eol    = no longer supported by its maker (no security fixes): WARN High
#             watch  = software the MSP wants to know about (unwanted, risky, licence): WARN Medium
#   Platform  windows, macos, linux or any
#   Name      one or more wildcard patterns separated by commas (* = any text, ? = one character),
#             case-insensitive, matched against the whole program / app / package name
#             (Windows: Apps & Features name; macOS: app name; Linux: package, snap or Flatpak name)
#   Version   optional wildcard patterns (same rules) matched against the version; empty = any
#   Date      last day the maker supported it (eol), or empty. Microsoft's lifecycle pages give
#             the end as 6:59:59 AM Pacific on the following day; this file uses the day before.
#   Reason    shown in the report
#   Source    where the date comes from
#   Checked   date the Source was last checked against this line, or "unverified"
#
# Checked = the date the Source page was read and showed this date. "unverified" means no
# official page could confirm it (the reason is in the comment above that line).
# Lines starting with # and empty lines are ignored.
